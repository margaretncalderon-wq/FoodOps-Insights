**Key Technical Concepts**
-   **Dynamic Data Linking during Import**: The migration module uses a find or create pattern. When importing transactional data (e.g., a sale), it first tries to find the associated client by a unique identifier (RNC) or name. If the client exists, it links the transaction; if not, it creates a new basic client record. This ensures data integrity.
-   **Config-Driven UI**: The UI for both the Data Migration and Scorecard features is driven by configuration objects/arrays in the code. This makes it easy to add new data types to import or new scorecard templates without major structural changes.
