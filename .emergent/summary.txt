**Key Technical Concepts**
-   **Multi-Tenant OAuth**: Implementation of a real OAuth 2.0 flow for a third-party service (Meta/Instagram) where a single central application (Kora) manages authentications for multiple independent tenants, storing tokens securely on a per-tenant basis.
-   **Public Sharing Links**: A system for generating secure, token-based, shareable links for application modules, allowing external users read-only access without needing an account.
-   **In-App Notification System**: A real-time notification feature with a backend model (), API endpoints for fetching/marking as read, and a frontend component () that polls for new updates to display to the user.
-   **Dynamic Template Seeding**: A backend endpoint () designed to populate the database with a default set of pre-designed templates, including their metadata and preview image URLs, for immediate use by new users.
